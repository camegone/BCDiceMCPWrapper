# BCDice MCP サーバ・ラッパー

## 概要

これは **BCDice** を **MCPサーバー** としてラップしたものです。BCDiceは **TRPG** 用のダイスボットで、**100以上の様々なゲームに対応しています**。このMCPサーバーは、標準的なダイスロールコマンド(**1d100**, **2d6**など)だけでなく、ゲームシステムのヘルプメッセージや、コマンドのパターンなども取得できます。

## 特徴

- BCDiceの **すべてのゲームシステム（クトゥルフやエモクロアなど）** をサポートしています。
- **ゲームシステムごとのダイスコマンド** を取得できます。
- コマンドの **パターンを取得できます**。
- 基本的なダイスコマンドだけでなく、複雑なコマンドやカスタム表などの **全機能が使えます**。

## インストール

前提として、**node.js** と **npm** がインストールされている必要があります。

### npxを使う

この内容を使っているMCPに対応したアプリの設定に記述します。

```json
{
  "mcpServers": {
    "bcdice": {
      "command": "npx",
      "args": [
        "-y",
        "@camegone/bcdice-mcp"
      ]
    }
  }
}
```

### リポジトリからインストールする

お好きな場所にクローンするか、zipファイルをダウンロードして展開します。

```bash
git clone https://github.com/camegone/BCDiceMCPWrapper.git
```

次に、以下のような内容をお使いのMCPクライアントの設定ファイルに書き込みます。**<YOUR_INSTALL_PATH>は、このリポジトリをインストールしたパスに書き換えてください。**

```json
{
  "mcpServers": {
    "bcdice": {
      "command": "node",
      "args": [
        "<YOUR_INSTALL_PATH>/BCDiceMCPWrapper/build/index.js"
      ]
    }
  }
}
```

## ツール一覧

このサーバーは以下のツールを提供します。

### 1. `rollDice`
指定したゲームシステムのルールに沿ってダイスロールを実行します。通常のダイス（`1d100` や `2d6+4` など）に加えて、各システム固有の判定コマンド（クトゥルフ神話TRPGの `CC<=50` など）も実行できます。
- **引数**:
  - `diceCommand` (文字列, **必須**): 実行するダイスコマンド式（例: `'1d100'`, `'3d6'`, `'2d6+4'`, `'CC<=50'` など）。
  - `system` (文字列, 任意, デフォルト: `'DiceBot'`): 対象のゲームシステム名（`getGameSystemsList` で取得可能。例: `'Cthulhu'`, `'Cthulhu7th'`, `'DiceBot'` など）。
- **返り値**:
  - ダイスロールの結果テキスト（成否判定や出目詳細など）。無効なコマンドの場合はそのシステムのヘルプメッセージを返します。
---
### 2. `getDescription`
指定したゲームシステムのヘルプメッセージ（利用可能なコマンド一覧や判定方法の説明）およびコマンドの正規表現パターンを取得します。
- **引数**:
  - `system` (文字列, 任意, デフォルト: `'DiceBot'`): 説明を取得したいゲームシステム名。
- **返り値**:
  - システムのヘルプメッセージ（コマンド仕様・書式）
  - システムのコマンド判定用正規表現パターン
---
### 3. `getGameSystemsList`
BCDiceで利用可能なすべてのゲームシステムの一覧を取得します。
- **引数**: なし
- **返り値**:
  - 利用可能な全ゲームシステムのIDや表示名などのメタデータ一覧（JSON形式）。
---
### 4. `rollUserDefinedTable`
ユーザーがテキスト形式で定義したオリジナル表（カスタム表）をロールして結果を取得します。
- **引数**:
  - `tableText` (文字列, **必須**): 表タイトル、ダイス式、各出目と対応テキストで構成されたテーブル定義テキスト。
    ```text
    表のタイトル
    1D6
    1:いち
    2:に
    3:さん
    4:し
    5:ご
    6:ろく
    ```
- **返り値**:
  - 表をロールした結果テキスト。
---
### 5. `getDiceBotVersion`
組み込まれている BCDice 本体のバージョンを取得します。
- **引数**: なし
- **返り値**:
  - BCDice のバージョン文字列（例: `BCDice version: 4.10.0`）。
---
### 6. `getMCPServerVersion`
この MCP サーバーのバージョンを取得します。
- **引数**: なし
- **返り値**:
  - MCP サーバーのバージョン文字列（例: `MCP server version: 1.0.1`）。
